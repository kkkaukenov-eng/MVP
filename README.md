# MVP Game Club — готовый статический сайт

## 1. Открыть на компьютере
Распакуйте ВЕСЬ ZIP в одну папку. Откройте index.html двойным щелчком в современном Chrome, Safari, Firefox или Edge. Не открывайте HTML прямо внутри архива. Интернет нужен только для переходов в WhatsApp, Instagram и 2GIS. Сборка, npm и сервер не нужны.

## 2. Загрузить в GitHub
1. Создайте новый репозиторий, например mvp-game-club. Для обычного бесплатного GitHub Pages выберите Public.
2. На компьютере откройте репозиторий → Add file → Upload files.
3. Перетащите СОДЕРЖИМО распакованной папки: index.html, css, js, assets, README.md и .nojekyll. Не загружайте сам ZIP.
4. Нажмите Commit changes. Папки css, js и assets должны остаться папками, index.html должен быть прямо в корне репозитория.
5. Если скрытый .nojekyll не загрузился, выберите Add file → Create new file, имя .nojekyll, затем Commit changes. Файл можно оставить пустым.
На телефоне загрузка вложенных папок бывает неудобной — предпочтительно использовать компьютер. Если создаёте файл вручную, в имени указывайте полный путь, например css/style.css, а внутрь вставляйте всё содержимое соответствующего файла. Одна только папка images без файлов не заменяет фотографии.

## 3. Включить GitHub Pages
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save. Дождитесь успешного действия Pages в разделе Actions. Ссылка появится в Settings → Pages. Обычно имеет вид https://ВАШ-ЛОГИН.github.io/mvp-game-club/.
Все пути относительные, сайт работает в подпапке репозитория. Если видите 404, проверьте ветку, наличие index.html в корне и завершение публикации.

## 4. Render Static Site
1. Загрузите проект в GitHub с указанной структурой.
2. В Render выберите New → Static Site (именно Static Site).
3. Подключите репозиторий, ветка main.
4. Root Directory: оставить пустым. Build Command: echo "Static site ready". Publish Directory: . (одна точка).
5. Нажмите Deploy Static Site. После успешной публикации откройте выданный адрес onrender.com.
Start Command не нужен — у Static Site нет серверного процесса. Если интерфейс просит Start Command, проверьте, что выбран Static Site, а не Web Service.

## 5. Что и где изменять
- js/main.js, начало файла: CLUB — телефон, WhatsApp (цифры без плюса), адрес, Instagram, 2GIS. Ссылки и адреса на странице берутся отсюда. Резервный телефон в noscript в index.html при замене измените отдельно.
- ROOMS в js/main.js: названия, номера ПК, характеристики, цены. Порядок цен: 1 час, 2+1, 3+2, День, Ночь. Таблица, карточки и расчёт автоматически используют эти значения.
- PACKAGES: названия, продолжительность и фиксированное начало пакетов. При изменении интервалов также обновите пояснения в index.html.
- index.html: тексты, акции, бонусы, блок Kaspi Red, режим работы, заголовок страницы и описание для поисковиков. Итоговое число ПК и максимальная частота на первом экране заданы явно — при смене оборудования обновите их.
- css/style.css: цвета, оформление, адаптивная версия.
- assets/images/: оптимизированные WebP. Можно заменить файлы, сохранив имена, либо изменить пути в HTML/JS. Для фото используйте реальные материалы клуба.
- assets/icons/favicon.svg: иконка вкладки.

## 6. Что работает сразу
Мобильное меню, модальные характеристики, увеличение фотографий, FAQ, выбор желаемого номера ПК, расчёт всех 15 основных тарифов, проверка обязательных полей/телефона/прошедшего времени, подготовка WhatsApp-сообщения и копирование текста.
Время заявки всегда трактуется как время Семей (UTC+5), независимо от настроек устройства посетителя. Для «Дня» начало фиксировано в 09:00, для «Ночи» — в 21:00; ночной пакет заканчивается в 09:00 следующего дня. Уже начавшийся пакет на сегодняшнюю дату заказать нельзя: нужно выбрать будущую дату либо уточнить условия у администратора.
Для отправки пользователь сам нажимает отправку в WhatsApp. Открытие приложения зависит от устройства. Если оно не открылось, есть кнопка копирования; при запрете буфера браузером появляется выделяемый текст. Персональные данные не записываются в localStorage, cookies или на сервер. Скрытой аналитики нет.
Школьный и студенческий тарифы не участвуют в расчёте: залы и условия их применения требуют уточнения у администратора. Бонусы не вычитаются автоматически.

## 7. Что потребует отдельной разработки
Это заявка, а не подтверждённая бронь. Администратор проверяет места и подтверждает условия. Реальные статусы компьютеров, автоматическое закрепление места, учёт времени и онлайн-оплата потребуют API программы клуба, серверной части, защиты доступа и интеграции с платёжным провайдером. Kaspi Red сейчас представлен информационным блоком; приёма денег, QR и подтверждения платежа на сайте нет.

## Фотографии
Использованы фрагменты предоставленных владельцем материалов: logo.webp — логотип из публикации Kaspi Red; standard/vip/bootcamp.webp — чистые фрагменты мониторов из фотографий соответствующих залов; entrance.webp — вход из предоставленного скриншота 2GIS. Интерфейс соцсетей и статусные строки удалены кадрированием. Помещение не дорисовывалось. Разрешение ограничено исходными скриншотами: для более детальной галереи замените их оригинальными снимками.

## Проверка этой версии
Программно проверены все 15 цен, диапазоны 1–25 / 26–35 / 36–40, окончание ночного пакета на следующий день (включая переход года), отклонение прошедшей даты, неправильного ПК, пустого имени и короткого телефона. Проверены синтаксис JavaScript, пути и целостность изображений.
В среде подготовки не удалось запустить браузер для визуальной проверки 390/1440 px и реальных кликов. Адаптивные стили предусмотрены, но финальную проверку отображения на устройствах следует выполнить после открытия index.html. Скриншоты готовой страницы по этой причине не приложены.
